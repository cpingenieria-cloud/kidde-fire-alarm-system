# 06. Normas y seguridad

## Objetivo
Establecer lineamientos de seguridad, respuesta y cumplimiento para la operación del sistema.

## Medidas de seguridad
- Desconectar energía antes de manipular cableado
- Usar equipo de protección personal
- Evitar trabajos en zonas con humo o riesgo activo
- Registrar todas las intervenciones
- Asegurar señalización de trabajo

## Procedimientos de emergencia
- Identificar zona de alarma
- Notificar personal responsable
- Evaluar riesgo real
- Evacuar según protocolo
- Verificar que el sistema quede en estado seguro

## Recomendaciones de cumplimiento
- Seguir manual del fabricante
- Revisar normativa local
- Mantener registro de inspecciones
- Capacitar personal operativo
