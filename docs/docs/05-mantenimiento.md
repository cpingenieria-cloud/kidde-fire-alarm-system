# 05. Mantenimiento

## Objetivo
Mantener la operatividad del sistema y asegurar su disponibilidad.

## Mantenimiento preventivo
- Inspección visual mensual
- Verificación de panel
- Revisión de alimentación
- Verificación de alarmas
- Limpieza de detectores
- Revisión de baterías

## Pruebas recomendadas
- Prueba semanal de alarma
- Prueba mensual de funcionamiento
- Prueba semestral de respaldo
- Prueba anual de integridad

## Registro de mantenimiento
Debe guardar:
- Fecha
- Usuario responsable
- Equipo revisado
- Hallazgos
- Correcciones realizadas
- Próxima revisión
