# 03. Configuración

## Objetivo
Definir la configuración del sistema para asegurar detección temprana, respuesta rápida y trazabilidad.

## Pasos recomendados
1. Identificar zonas del edificio
2. Asignar detectores por área
3. Definir prioridades de alarmas
4. Configurar tiempos de activación
5. Determinar responsables de respuesta
6. Establecer pruebas periódicas
7. Registrar cambios de configuración

## Configuración sugerida
- Zonas por piso
- Zonas por área funcional
- Alarmas por prioridad
- Notificación local y remota
- Tiempo de retardo de evacuación
- Señales visuales y sonoras

## Recomendaciones
- No mezclar zonas sin criterio
- Mantener planos actualizados
- Usar etiquetas claras
- Registrar cambios
- Validar configuración con pruebas funcionales
