# 04. Instalación

## Preparación del sitio
- Revisar planos
- Identificar áreas con riesgo
- Confirmar accesos a paneles
- Verificar líneas de alimentación
- Revisar rutas de cableado

## Procedimiento general
1. Instalar panel de control
2. Ubicar detectores por zona
3. Instalar botones manuales
4. Conectar sirenas y luces
5. Revisar continuidad eléctrica
6. Verificar conexiones de tierra
7. Conectar sistema de alimentación
8. Ejecutar pruebas iniciales

## Recomendaciones de ubicación
- Detectores lejos de corrientes de aire
- Evitar áreas con altas temperaturas
- Mantener acceso para mantenimiento
- Ubicar alarmas en rutas visibles
- Colocar botones manuales cerca de salidas

## Mecanismos de comprobación
- Prueba de continuidad
- Prueba de alarma
- Verificación de alimentación
- Verificación de indicadores
- Registro de resultados
