# 02. Componentes del sistema

## Componentes principales
- Panel de control
- Detectores de humo
- Detectores de calor
- Estaciones manuales
- Sirenas y alarmas
- Indicadores visuales
- Módulos de supervisión
- Fuente de alimentación
- Batería de respaldo
- Cableado y accesorios

## Descripción funcional

### Panel de control
Es el núcleo del sistema. Permite:
- supervisar zonas
- activar alarmas
- rastrear eventos
- gestionar el estado del sistema

### Detectores
Pueden ser:
- de humo
- de calor
- combinados
- ubicados estratégicamente en áreas de riesgo

### Alarmas
Incluyen:
- sirenas
- luces estroboscópicas
- señalización de evacuación

### Fuente de alimentación
Debe garantizar:
- alimentación estable
- continuidad operativa
- respaldo en caso de corte eléctrico

## Inventario sugerido

| Componente | Cantidad | Ubicación |
| --- | ---: | --- |
| Panel de control | 1 | Sala técnica |
| Detectores de humo | Variable | Áreas críticas |
| Detectores de calor | Variable | Cocina / planta |
| Sirenas | Variable | Áreas comunes |
| Botones manuales | Variable | Salidas / pasillos |
| Fuente de alimentación | 1 o más | Sala técnica |
