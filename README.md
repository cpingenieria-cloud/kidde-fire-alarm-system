# kidde-fire-alarm-system

Documentación técnica, implementación y diagrama de un sistema de incendios Kidde.

## Descripción
Proyecto orientado a documentar la arquitectura, configuración, instalación, pruebas y mantenimiento de un sistema de alarma contra incendios con enfoque técnico y profesional.

## Objetivo
Establecer una referencia técnica clara para la implementación de un sistema de detección y alarma contra incendios basado en equipos tipo Kidde.

## Alcance
- Detección de humo y calor
- Panel de control y supervisión
- Señalización visual y sonora
- Instalación y mantenimiento
- Capacitación y operación
- Documentación de seguridad

## Componentes del sistema
- Panel de control principal
- Detectores de humo
- Detectores de calor
- Estaciones manuales
- Sirenas y alarmas
- Indicadores visuales
- Fuente de alimentación
- Baterías de respaldo
- Cableado y accesorios
